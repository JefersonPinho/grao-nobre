# Produtos Naturais

Catálogo para escolher produtos a granel, montar um pedido e enviar pelo WhatsApp.

```bash
npm install
npm run dev
```

Os produtos ficam em `src/data/products.ts`. Para trocar a foto de um item, coloque o arquivo em `public/products` com o código do produto, por exemplo `public/products/1.001.webp`.
